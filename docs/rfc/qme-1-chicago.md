# Expanded Chicago qualification

Q+ is conjunctive: ExactSubject ∩ Provenance ∩ CanonicalSemantics ∩ AuthorityBound ∩ ConsequenceBound ∩ IndependentObservation ∩ Receipt ∩ ReplaySafe ∩ Falsifiers ∩ Migration. A missing term cannot be compensated by stronger scores elsewhere. MX0 is admitted net-zero value; negative value means added capability increases total qualified risk/cost; MXinf is an unbounded consequence term and fails closed.

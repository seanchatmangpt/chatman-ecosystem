# 33. Reconstitution from Evidence

The strongest resilience property is not “the current deployment can recover.” It is “the system's knowledge survives the loss of its projections.”

## Destroy the projection

Imagine deleting generated source, Terraform files, Kubernetes manifests, portal configuration, CI YAML, documentation projections, and deployment bundles.

What remains should be sufficient to reconstruct them if those projections are genuinely derived.

The reconstitution set includes the admitted semantic graph, manufacturing rules, toolchain identities, policies, proof obligations, and relevant evidence.

## Recover the graph

For a mature ggen-native system, the graph is already canonical. For a legacy system, ggen-legacy must recover it from surviving artifacts and observed behavior.

The distinction should remain visible: recovered semantics can carry lower standing until independently admitted.

## Replay manufacture

Reconstitution performs deterministic manufacture where possible:

\[
(G^*, \mu, T) \rightarrow A'
\]

Then it compares `A'` with the historical artifact or with the historical semantic contract.

Byte-for-byte identity is ideal for deterministic projections but not always required if the class admits multiple semantically equivalent outputs.

## Reestablish standing

Historical receipts establish what the previous subject did. A reconstituted artifact is a new exact subject unless byte identity and all relevant context are preserved.

It must climb its required evidence ladder again.

This is why reconstitution is stronger than restoring a backup: it proves the manufacturing system still knows how to create the capability.

## Disaster recovery becomes semantic

Traditional disaster recovery stores copies of implementation. Semantic reconstitution stores the constitution of manufacture.

Copies remain useful for speed. They are caches, not the ultimate source of recoverability.

## Falsifier

A system is not reconstitutable if deleting one generated file destroys business meaning that is not recoverable from any canonical semantic source or admitted evidence.

## Operational exercise

Choose one bounded subsystem and perform a paper reconstitution. List every file that can be deleted and regenerated, every canonical input required, and every piece of meaning that still exists only in a projection. The last category is reconstitution debt.

# 9. Conway’s Law and the Reciprocal

**Executive thesis:** Organizations project their communication structure into systems; a sufficiently authoritative semantic substrate can also push the organization to reorganize around shared operational law.

## Why agent swarms can preserve silos

If application, cloud, security, data, and AI teams each operate separate agents with separate prompts and local context, automation can reproduce the existing seams at machine speed. The system becomes a high-throughput projection of organizational fragmentation rather than a coherent enterprise model.

## Canonical semantics as counterpressure

A canonical graph does not erase legitimate boundaries. It makes shared identities, dependencies, authority, and evidence explicit across them. Code, APIs, policies, cloud resources, and documentation can then be projections of common semantics instead of negotiated copies maintained by each department.

## The reciprocal

The usual reading of Conway is organization → system. The reciprocal is system → organization: when the operational substrate becomes more authoritative than tribal memory, teams can reorganize around capabilities, law, evidence, and consequences rather than around the artifacts they historically owned. Receipts can replace some approval theater; shared ontology can replace repeated semantic meetings.

## Operating practice

Map one enterprise capability across organizational seams. Identify how many groups maintain independent representations of the same identity, rule, or state. Make the shared semantic object authoritative first; only then consider reorganizing processes around it.

## Diagnostic question

Which system boundaries exist because of organizational seams rather than domain law?

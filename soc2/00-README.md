## The one thing this binder cannot do

Issue an opinion. That is the one section of a real SOC 2 Type II report —
the Independent Service Auditor's Report — that requires an actual
licensed CPA firm, after an actual independent audit engagement. Every
document above exists to make that engagement, when it happens, start from
real evidence instead of a blank page — not to make the engagement
unnecessary.

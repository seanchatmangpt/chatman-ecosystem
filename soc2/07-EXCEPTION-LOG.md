
# 07 — Exception log

Every control marked `EXCEPTION` in `03-CONTROL-MATRIX.md` should have a
matching row here — a real finding, its risk level, and its remediation
status. An empty log is either genuinely clean or simply not yet
populated; this file does not distinguish those two cases for you, and
neither does the control matrix's own `EXCEPTION` count — check both.

## How to log an exception

```turtle
[] a prov:Entity ;
    rdfs:label "MFA not enforced for one break-glass admin account" ;
    dcterms:subject "CC6" ;
    dcterms:type "EXCEPTION" ;
    dcterms:relation "MEDIUM" ;
    dcterms:description "Break-glass account bypasses SSO/MFA by design; access is logged but not MFA-gated." ;
    dcterms:isReplacedBy "Add hardware-key MFA gate to break-glass path" ;
    dcterms:hasVersion "in progress" .
```

`dcterms:relation` must be one of this pack's `RISK-LEVELS` notations:
`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`.

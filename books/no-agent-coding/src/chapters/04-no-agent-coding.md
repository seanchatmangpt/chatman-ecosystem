# 4. No Agent Coding

**Executive thesis:** No Agent Coding is the move from programming by repeated interpretation to manufacturing by derivation from admitted semantics.

## The category

The name is intentionally provocative because agentic coding is widely treated as the endpoint. No Agent Coding proposes a different endpoint: intelligence at the frontier, determinism in the core. Agents can discover, compare, falsify, and propose. They do not have to remain permanent middleware between known intent and every future implementation.

## The core transform

The Chatman form is O → admission → O* → μ → A. O is what was observed or proposed. O* is the bounded observation that has been admitted under explicit constraints. μ is lawful manufacture. A is the resulting artifact. The code is downstream of admitted meaning rather than the primary place from which meaning must later be reconstructed.

## What “no agent” does not mean

It does not mean no AI, no humans, no judgment, or no code. It means no unnecessary agent in a known deterministic path. A novel incident may require investigation. A new product may require design. A new ontology mapping may require judgment. Once the decision class is stable, the recurring path should stop paying for interpretation.

## Operating practice

Draw the current path for one high-frequency engineering action. Circle every point where a person or model rereads context and makes a decision already made elsewhere. Those circles are candidates for compilation into ontology, constraints, queries, generators, formal admission, or deterministic workflows. Start with one bounded class and earn standing before expanding.

## Diagnostic question

What known class could be removed from the agentic path this quarter?

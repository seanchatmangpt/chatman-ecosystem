# 62. The Canonical Correspondence

A mature ecosystem should preserve a correspondence from semantic knowledge all the way to release evidence:

\[
Graph \rightarrow Query \rightarrow ggen \rightarrow Formal\ Admission \rightarrow Runtime \rightarrow BRCE \rightarrow Receipt \rightarrow Replay \rightarrow Release
\]

The strength of the system lies less in any individual component than in the commutation among them.

## Graph

The graph owns durable semantic identity and relationships.

## Query

Queries select a bounded semantic view for a manufacturing purpose. The query should not invent hidden business meaning.

## ggen

ggen renders the selected semantics into target representations.

## Formal admission

Constraints, theorem checks, and validation packs eliminate candidates that violate encoded law.

## Runtime

The artifact is exercised in the environment required by the claim. GymAct may provide synthetic runtime evidence before production.

## BRCE

Consequential real-world execution crosses the brokered authority boundary.

## Receipt

Evidence binds the exact transition and observed postcondition.

## Replay

The system preserves the causal and toolchain context required to reconstruct the claim.

## Release

Publication exposes an exact subject with bounded standing. A release does not retroactively certify unobserved behavior.

## Correspondence failures

Many software failures are really broken correspondences: docs describe a different API, CI validates a different SHA, a Terraform state points at an unexpected account, an MCP tool bypasses policy, or a receipt cannot identify the generated source.

Post-AGI manufacture should test these relationships directly.

## Falsifier

The correspondence is incomplete if a projection or actuation can acquire semantics that cannot be traced back to admitted graph state or explicitly classified substrate behavior.

## Operational exercise

Choose one release artifact and walk backward through all nine stages. Record exact identities at every stage. Any heuristic join is a potential semantic fracture.

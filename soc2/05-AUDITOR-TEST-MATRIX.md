
# 05 — Auditor test matrix (internal rehearsal)

Mirrors the **structure** a real SOC 2 Type II report's Section 4 ("Trust
Services Criteria, Related Controls, and Tests of Controls Performed by
the Service Auditor, and Results of Tests") would carry — control-by-
control test procedures and results — so this project can rehearse what a
real audit will examine before engaging one. Generated from this project's
own self-performed test facts, not an auditor's.

## What is deliberately left blank

A real SOC 2 Type II report has five parts. This binder only ever models
parts 3 and 4. Parts 1, 2, and 5 require a real, independent, licensed CPA
firm and cannot be rehearsed, simulated, or generated:

1. **Independent Service Auditor's Report** — the auditor's own opinion.
   **Left blank here, structurally, on purpose.** No fact any template in
   this pack renders, and no fact `gates/010_no_compliance_verdict.rq`
   admits, can ever populate this section.
2. **Management's Assertion** — see `02-MANAGEMENT-ASSERTION.md`: this
   project may legitimately draft its own assertion, but it is a
   management statement, not evidence, and this pack only scaffolds the
   template — the content is yours to write.
3. **System Description** — see `01-SYSTEM-DESCRIPTION.md`.
4. **Tests of controls and results** — modeled below.
5. **Other information** (management responses to exceptions) — see
   `07-EXCEPTION-LOG.md`'s remediation column.

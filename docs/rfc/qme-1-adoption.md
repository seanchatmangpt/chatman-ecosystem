# QME-1 Adoption

Consumers reference the canonical QME-1 specification rather than copying it. Adoption sequence: inventory private semantics; bind canonical owners; declare exact subject and evidence horizon; classify authority and consequence; import negative knowledge with boundaries and falsifiers; add independent observation; make replay non-actuating; add compatibility aliases; prove parity; retire duplicates.

A consumer is not conformant merely because it emits a receipt. Receipt, evidence, policy, plan and signature remain distinct from authority and standing.

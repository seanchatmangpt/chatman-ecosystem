# HDITC projection policy

The canonical authored inputs for this book are `SUMMARY.spec.*.md` plus `scripts/generate_hditc_book.py`. The files under `src/` and `book.toml` are deterministic projections and must be regenerated rather than hand-edited.

A generated manuscript has structural standing only when every `SUMMARY.md` target exists, every generated Markdown file is non-empty, and the expected chapter closure is reproduced. Structural standing is not an `ALIVE` claim for rendered mdBook output; that requires execution of the actual mdBook build against the exact subject.

## Decision

The seven-day fleet scan does **not** change the Chatman Equation:

\[
A = \mu(O^*)
\]

It strengthens the machinery that determines how live repository observations may contribute to \(O^*\).

A repository head is \(O\), not \(O^*\). QME is one admissibility regime for earning the star:

\[
O \xrightarrow{QME} O^* \xrightarrow{\mu} A
\]

The expanded form \(A=\mu(Q(O))\) is therefore an implementation expansion, not a replacement law. QME can qualify evidence; it cannot manufacture authority.

## Why this improves the equation

The equation becomes more useful as implementations multiply because repository identity is not architecture. New machinery can be absorbed by proving where it sits:

- observation contributes candidate evidence;
- admission determines \(O^*\);
- manufacture implements \(\mu\);
- consequence requires separate authority;
- receipts bind exact subjects;
- replay verifies without silently repeating consequence;
- QME preserves negative knowledge and hardening.

This makes model intelligence increasingly replaceable. A repeated reasoning edge can migrate from an LLM into an ontology, Datalog rule, planner, generator, verifier, state machine, or proof without changing the surrounding law.

\[
\frac{d(\text{required intelligence for solved classes})}{dt} < 0
\]

is therefore an operational consequence of accumulated qualified machinery, not an additional axiom.

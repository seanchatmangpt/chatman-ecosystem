## Scope

This RFC is framework-neutral. It defines the dependency-closed normative
core and a machine-checkable conformance claim. Repositories named under
*Reference mapping* are reference evidence; nothing here depends on them.

## Normative core

Each law has one canonical id. A conformance claim MUST carry exactly one entry
per id.

| Id | Law |
| --- | --- |
| `QMX` | Qualified Machine Experience: every claim binds an exact subject and an evidence horizon. |
| `NHS` | No Hidden Semantics: every term is defined by exactly one owner; no term is defined implicitly. |
| `CANON` | Canonical ownership: one canonical source per fact; projections are disposable. |
| `CSEP` | Consequence separation: `SELECT`, `CONSTRUCT`, `DO` are distinct authority classes. |
| `IOBS` | Independent observation: standing is verified by an observer distinct from the producer. |
| `NAREP` | Non-actuating replay: replay never performs a consequence. |
| `MXNEG` | MX0/MXinf negative-value calculus: a change with non-positive net value is refused. |
| `CHEST` | Reverse/Negative Chesterton: a constraint is removed only after its origin is observed and its removal is receipted. |
| `ACD` | Adversarial Constraint Distillation: constraints are distilled from refused inputs. |
| `HARD` | Cumulative metallurgical hardening: each admitted failure adds a permanent negative fixture. |
| `CHIC` | Conjunctive Chicago qualification: all qualification gates must hold; none substitutes for another. |
| `SMAN` | Semantic manufacture: artifacts are `A = μ(O*)`; artifacts are never authored ahead of observation. |
| `XCAP` | External capability absorption: an external capability is admitted only as a pinned, re-qualified projection. |
| `PROF` | Additive domain profiles: a profile only adds obligations and cannot weaken a core law. |

## Conformance claim

A claim (`schemas/factory-e-conformance.schema.json`) names:

- `subject`: `repo`, `ref`, 40-hex `sha`;
- `evidence_horizon`: `observed_at`, optional `expires_at`;
- `laws`: one entry per core id, each with `owner`, `standing`, `evidence`;
- `terms`: `{term, owner}` pairs, unique by term;
- `consequences`: each with a single class; `DO` requires `authority` and `receipt`;
- `replay.actuating`: MUST be `false`;
- `profiles`: optional additive profiles.

Evidence uses `OBSERVED`, `EXECUTED`, `CHANGED`, `VERIFIED`, `EXCLUDED` and MUST
name the same subject as the claim. Standing is one of `UNKNOWN`,
`PARTIAL_ALIVE`, `ALIVE`, `BLOCKED`, `BUILD_BROKEN`, `UNSUPPORTED`.

`ALIVE` requires, for that law: at least one `EXECUTED` item on the exact
subject, and at least one `VERIFIED` item whose `observer` differs from its
`producer`.

## Typed refusals

`SCHEMA_INVALID`, `MISSING_LAW`, `DUPLICATE_LAW`, `STALE_OR_FOREIGN_SUBJECT`,
`EVIDENCE_HORIZON_EXPIRED`, `ALIVE_WITHOUT_EXECUTION`, `SELF_CERTIFIED`,
`HIDDEN_SEMANTICS`, `CONSEQUENCE_UNAUTHORIZED`, `ACTUATING_REPLAY`,
`PROFILE_WEAKENS_CORE`, `NEGATIVE_VALUE_CHANGE`, `CHESTERTON_VIOLATION`,
`VACUOUS_COURT`, `VIOLATION_OBSERVED`, `UNHARDENED_FAILURE`,
`CHICAGO_NOT_CONJUNCTIVE`, `EXTERNAL_NOT_REQUALIFIED`.

## Executable semantic checks

Optional claim sections are checked when present:

- `changes` (`MXNEG`): every `net_value` MUST be > 0.
- `constraint_removals` (`CHEST`): `origin_observed` true and a `receipt`.
- `distilled_constraints` (`ACD`, anti-vacuity): `attempt_observed` true and
  `violation_observed` false; an unreached boundary is `VACUOUS_COURT`.
- `hardening` (`HARD`): each `fixture` MUST exist inside this repository.
- `qualification` (`CHIC`): `CHIC` may be `ALIVE` only if all ten Q+ terms
  (ExactSubject … Migration, see `qme-1-chicago.md`) are true; no term
  compensates another.
- `external_capabilities` (`XCAP`): 40-hex `pin_sha` and `requalified` true.
- `artifacts` (`SMAN`): each names a non-empty `observed_from`.

## Relation to existing packages

The Universal Laws package (`docs/rfc/universal-laws/`) and QME-1
(`docs/rfc/qme-1-*.md`) own the law text and Chicago algebra. This RFC adds
only a per-subject claim envelope and does not become a parallel semantic
owner. Fleet references: `v26.9.29-factory-e-reference-map.json`.

## FIBO profile (additive)

Profile `fibo` adds the obligation that financial terms in `terms` name an
owner under the FIBO namespace and appear in `profile_terms`. It MUST NOT
alter any core law entry. A profile that lists `overrides` is refused with
`PROFILE_WEAKENS_CORE`.

## Reference mapping (evidence, not dependency)

GraphLaw: semantic law-state. Ash / ash_graphlaw: projection. ash_r2rml: VKG
observation. ash_a2a: consequence protocol (PreparedEffect, receipt, replay).
Affidavit: cryptographic trust. Beam4PM: process experience. XaaS: runtime
composition. ggen-marketplace: writable manufacture. CASTLE: product-level
consequential constitution. `ggen` is untouched by this RFC.

## Executable runner

`scripts/factory_e_conformance.py` checks a claim without network access and
without side effects. It only reads the claim and prints a verdict.

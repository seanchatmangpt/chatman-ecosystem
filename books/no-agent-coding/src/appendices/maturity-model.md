# Appendix C. No Agent Coding Maturity Model

## L0 — Human-coded

Meaning lives primarily in people, tickets, and implementation. Review reconstructs intent from artifacts. Automation is local.

## L1 — AI-assisted

Models accelerate search and authoring, but humans remain the main semantic and authority boundary. Output rate rises while architecture remains conventional.

## L2 — Vibe-coded

Models produce substantial implementation from natural-language intent. Verification is mostly downstream. Candidate throughput can exceed semantic closure.

## L3 — Agentic

Models plan, use tools, maintain context, and may construct or actuate across repositories and services. Capability rises, but repeated interpretation remains central.

## L4 — Semantically governed

Canonical identities, public ontology, admission constraints, SELECT/CONSTRUCT/DO separation, receipts, and replay govern important capability classes. Agent output is explicitly candidate material.

## L5 — Deterministically manufactured

Known classes are projected from admitted semantics through deterministic manufacturers. Agents are confined to frontier discovery and exception handling. One semantic mutation can generate many synchronized surfaces, and normal consequential paths are receipted and replayable.

Maturity is per capability class, not a badge for the entire organization. A company can be L5 for one bounded class and L1 for another without contradiction.

# Appendix D. Executive Diagnostic

Ask these questions in architecture and operating reviews:

1. Where does the authoritative meaning of this capability live?
2. Which decisions are being rediscovered by humans or models?
3. What converts raw observation into admitted O*?
4. Which artifacts are deterministic projections, and which contain independent semantics?
5. What is the real runtime or external boundary for the crown claim?
6. What negative fixture proves the verifier is not vacuous?
7. Can the exact claim be replayed by another operator?
8. Which operation is SELECT, which is CONSTRUCT, and which is DO?
9. Who or what grants DO authority, and can credentials bypass it?
10. What is represented in the possibility graph versus active admitted WIP?
11. Which enterprise concepts are duplicated across repositories or departments?
12. What legacy fence is still UNKNOWN?
13. What is the smallest Gall pier supporting the next layer of complexity?
14. Which recurring class is ready to become a ggen pack or another deterministic mechanism?
15. What activity would disappear if this architecture succeeded?

The last question is especially important. A deterministic enterprise should eliminate categories of recurring work. If the proposed transformation only creates a faster queue for the same interpretation, it has improved an agent without changing the architecture.

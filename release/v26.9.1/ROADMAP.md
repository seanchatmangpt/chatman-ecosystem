# v26.9.1 Release Roadmap

Target: **2026-09-01**.

## Definition of Done

v26.9.1 is not “all repositories green.” It is one exact, dependency-closed ecosystem subject whose required components are individually ALIVE and whose Fortune-5 capstone executes through the admitted chain.

```text
Define -> Measure -> Explore -> Develop -> Implement
```

### Define

- Freeze release roles, exclusions, CTQs, authority boundaries, and exact component coordinates.
- Admit the initial repository/ref/SHA graph in `manifest.toml`.

### Measure

- Execute each repository's canonical verifier against the exact admitted SHA.
- Record observed, executed, changed, verified, blocked, unsupported, and inferred facts separately.
- Replace each component's `UNKNOWN` only with evidence earned by that exact subject.

### Explore

- AutoFDE-Lab owns planner league, planner x role x world admission, cross-play, TRIZ/DOE/Monte-Carlo exploration, and falsification.
- Exploration produces candidates; it does not grant product or DO authority.

### Develop

- ggen manufactures deterministic projections from admitted graphs.
- mfact/Lean admits load-bearing formal claims.
- GymAct closes the selected real-world gym profile with unit proof plus real episode/OCEL/replay evidence.
- wasm4pm/wasm4pm-compat close process type-law and execution evidence.
- affidavit verifies the composed receipt DAG without becoming decision authority.

### Implement

Run one immutable release candidate:

```text
exact manifest
  -> semantic admission
  -> manufacture
  -> formal verification
  -> planner capstone
  -> GymAct bounded actuation
  -> OCEL/process verification
  -> provenance verification
  -> replay
  -> Fortune-5 fdegym capstone
  -> crown
```

## Release blockers

The first manifest contains only release-blocking repositories. Demonstration gyms, historical repositories, third-party forks, UI experiments, and source archaeology stay outside the crown unless dependency closure proves otherwise.

`fdegym` is the capstone. Its current identity is pinned, but its standing remains `UNKNOWN` until the capstone is observed against that exact subject.

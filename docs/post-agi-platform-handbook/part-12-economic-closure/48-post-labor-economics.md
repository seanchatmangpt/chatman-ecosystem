# 48. Post-Labor Software Economics

If intelligence makes code, configuration, documentation, and routine analysis extremely cheap, software economics does not disappear. Scarcity moves.

## Generation approaches abundance

The marginal cost of producing another plausible implementation can approach zero relative to historical labor costs.

That makes “lines of code produced” and raw commit counts increasingly weak proxies for economic value.

The scarce objects become the things generation cannot simply assert into existence.

## Verification remains scarce

Runtime behavior must still be observed. Physical and external systems still impose time. Independent validators still consume compute and environment access. Some properties require integration with scarce resources.

As candidate supply grows, mechanical verification becomes more valuable.

## Authority remains scarce

Permission to change a production system, transfer money, publish a release, or alter a physical environment is consequential precisely because not every capable actor should possess it.

Post-AGI systems can automate authority policy without making authority infinite.

## Standing remains scarce

An artifact with evidence-backed standing is more valuable than one of a million plausible generated candidates.

This changes the software factory's objective:

\[
Value \not\propto Generated\ Artifacts
\]

but more closely:

\[
Value \propto Closed\ Capabilities \times Transferability \times Standing
\]

## Coordination work can collapse

When one semantic source produces many projections, a large class of synchronization meetings, tickets, handoffs, and documentation updates disappears.

This is not merely labor substitution. It is work elimination through representational closure.

## New work shifts to frontier discovery

Intelligence should spend its expensive reasoning on unknown classes, contradictory observations, new constraints, formalization gaps, and environments whose ontology has not yet closed.

Repeated solved work should become deterministic manufacture.

## Falsifier

A claimed post-labor factory is still human-era automation if it uses cheap generation to create more artifacts while leaving admission, verification, coordination, and class closure as growing manual queues.

## Operational exercise

Measure one team's work by categories: discovery, semantic translation, repeated construction, verification, authority, coordination, and repair. Identify which repeated categories disappear if the capability is closed into ontology plus ggen plus evidence.

# Appendix M — Vision 2030 Capability Matrix

Vision 2030 is a target architecture, not a statement of current standing.

| Capability | 2026 target | 2030 target |
|---|---|---|
| Marketplace discovery | Curated vendor packs | Machine-acquired protocol/ontology candidates |
| Product modeling | Canonical commercial graph | Cross-industry commercial ontology closure |
| Listing generation | Deterministic metadata projections | Continuous multi-market compilation |
| Entitlement adapters | Generated structural adapters + qualified runtime | New-market adapter synthesis from admitted contracts |
| Deployment packaging | Helm/container/IaC/vendor wrappers | Target compilation across cloud/edge/sovereign markets |
| Qualification | Static + gym + sandbox + live | Continuous differential requalification |
| Security evidence | Control/evidence mapping | Machine-readable evidence exchange |
| Procurement | Human-led with machine evidence | Protocolized multi-admission workflows |
| Pricing | Governed product policy | Simulation-assisted pricing with explicit authority |
| Co-sell/channel | Marketplace-specific partner workflows | Canonical multi-party transaction graph |
| Operations | Commercial SRE | Bounded autonomous repair under BRCE |
| Receipts | Exact-subject evidence DAG | Cross-organization verifiable receipt fabric |
| Standing | Capability-specific ALIVE | Continuous standing under drift-aware replay |

## Non-negotiable 2030 invariants

- Legal interpretation is not inferred from model confidence.
- Credentials do not imply authority.
- Generated code does not imply standing.
- Marketplace approval remains an external fact.
- Customer rights cannot change without an admitted commercial transition.
- Financial DO is idempotent and receipted.
- Replay does not re-actuate.
- Unknown future marketplaces extend the graph rather than forcing a rewrite.
- Product identity remains invariant under admitted projections.
- Evidence is specific enough to falsify every important commercial claim.

The end state is deliberately boring: a new marketplace is mostly a new compilation target plus a qualification problem, not a new business architecture.

# 32. Migration Playbook: From Agentic to Deterministic

**Executive thesis:** The transition to No Agent Coding should itself follow Chesterton, Gall, Little, Conway, Rice, and DfCM rather than attempting a deterministic big bang.

## Stage 0: observe

Freeze the exact subject and inventory the current path: humans, agents, prompts, repositories, tools, approval steps, runtime consequences, and evidence. Do not begin by rewriting. Identify which decisions are novel, repeated, unknown, or already mechanized.

## Stage 1: fence and model

Preserve unknown structures, map public ontologies, create canonical identities, capture contradictions, and define the bounded admission rule. Use DfCM to keep viable alternatives represented without turning them all into active projects.

## Stage 2: first Gall pier

Select one high-frequency, low-authority class. Build the semantic source, projector, positive witness, negative falsifier, receipt, and replay. Keep consequential DO outside the new path until the construction surface has standing.

## Stage 3: retire the recurring interpreter

Route normal admitted instances through deterministic manufacture and keep exceptions on the frontier. Measure the reduction in rediscovery and WIP. Expand by adjacent semantic class only after the first pier remains stable under replay and drift checks.

## Diagnostic question

What is the first bounded class you can migrate without rewriting the whole enterprise?

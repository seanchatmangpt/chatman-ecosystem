# Appendix J — Chateco Repository Registry

This appendix is a reference surface for the Chateco doctoral program. Its source correspondence is **Declaration of Originality**.

This manuscript presents the Chatman Equation as an original synthesis and formal research program. The equation distinguishes partial observation, admitted observation, lawful manufacture, artifact, receipt, and replay. Prior work is cited where the thesis depends on established results in accounting history, formal logic, workflow theory, AI planning, typestate programming, semantic-web standards, process mining, software verification, and operations research.

The repository accompanying the thesis separates authored claims from generated structure. Generated navigation, assembled outputs, and validation reports are identified as such. No generated text or source file is treated as formal proof merely because it was emitted by a tool. Formal standing is assigned only by the relevant admission mechanism, such as a proof kernel, compiler, schema validator, planner result algebra, authorization broker, or replay verifier.

## Standing rule

Entries in this appendix are descriptive until bound to exact repository, ref/SHA or artifact digest, owning verifier, and receipt/replay evidence. Registry membership is not operational standing.

The immediate opportunity is not to create another feature surface; it is to make **fresh composition truth** mechanically stronger than stale but individually valid evidence.

The core failure mode is:

`component movement → old pin/receipt remains locally valid → composition consumes stale evidence → broader standing is overstated`.

Recent evidence adds two concrete variants:

- XaaS demonstrates that a real foreign key/reference can exist while the referenced resource belongs to the wrong authority/organization. **Existence ≠ authorized relationship.**

## How to add a row

Assert one `prov:Entity` per criterion in your own `ontology.ttl` (see
this pack's README for the full shape):

```turtle
[] a prov:Entity ;
    dcterms:subject "CC6" ;
    dcterms:type "TESTED" ;
    dcterms:contributor "platform-team" ;
    dcterms:source "platform-console/k8s/rbac.yaml" ;
    dcterms:description "Namespace-scoped RBAC, verified via cross-tenant access test." .
```

`dcterms:type` must be one of this pack's `IMPL-STATUS` notations:
`NOT-STARTED`, `PLANNED`, `IN-PROGRESS`, `IMPLEMENTED`, `TESTED`,
`EXCEPTION`, `NOT-APPLICABLE`. A criterion with `EXCEPTION` status should
have a matching row in `07-EXCEPTION-LOG.md`.

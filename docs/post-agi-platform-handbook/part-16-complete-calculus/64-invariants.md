# 64. The Constitutional Invariants

The ecosystem can be compressed into a small set of non-collapse laws. These laws are deliberately harder to optimize away than any particular tool.

## Observation does not imply admission

\[
OBSERVED \not\Rightarrow ADMITTED
\]

The system can see a fact without accepting it for the current subject or purpose.

## Admission does not imply construction

\[
ADMITTED \not\Rightarrow CONSTRUCTED
\]

A lawful input may still have no viable manufacturing path.

## Construction does not imply authority

\[
CONSTRUCTED \not\Rightarrow AUTHORIZED_{DO}
\]

A perfect plan can remain forbidden to actuate.

## Execution does not imply success

\[
EXECUTED \not\Rightarrow VERIFIED
\]

The command ran. The intended postcondition still needs evidence.

## Success does not imply standing

A local postcondition may succeed while broader release obligations remain unsatisfied.

\[
Checkpoint \not\Rightarrow Crown
\]

## Capability does not imply authority

Tool access, credentials, model skill, connector availability, or network reachability are implementation capabilities.

They are not permission.

## Generated does not imply canonical

Projection bytes do not outrank the semantic source from which they were manufactured.

## Proof does not imply reality

Formal validity is scoped to the model and assumptions. Runtime correspondence remains an evidentiary obligation.

## Hash does not imply origin

Content identity is not authenticated provenance.

## Workflow does not imply run

A declared automation is not evidence that the automation executed successfully against the exact subject.

## Zero unreceipted actuation

Finally:

\[
DO \Rightarrow Receipt
\]

Every consequential transition must enter the evidence graph.

## Falsifier

Any optimization that requires collapsing one of these distinctions must prove an equivalence strong enough to preserve the excluded failure modes. Convenience is not an equivalence proof.

## Operational exercise

Use the invariants as an architecture review. For every proposed shortcut, name which non-collapse law it approaches and what evidence would prove the shortcut preserves the same boundary.

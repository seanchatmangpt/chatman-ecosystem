- [ ] Lumen (`plugin_lumen_lumen`) — semantic code search over the indexed
  codebase; used as the first tool for code discovery instead of grep/find.
  Available as a Claude Code plugin — install it and it indexes automatically
  on first use.

### Skills to Know About
- `/loop` — schedule a recurring or self-paced prompt (cron-style or dynamic
  self-pacing); the most-used command by far, for long-running/autonomous
  work.
- `/model` — switch the active model for the session.
- `/superpowers:dispatching-parallel-agents` — fan out work across multiple
  subagents in parallel.
- `/compact` — compact the conversation when context gets long.
- `/deep-research` — multi-source, fact-checked research reports with
  adversarial verification.
- `/superpowers:finishing-a-development-branch` — wrap up a branch (used
  once, worth knowing about).
- `/superpowers:brainstorming` — structured brainstorming before planning
  implementation.

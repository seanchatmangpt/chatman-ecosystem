
# 02 — Management's assertion

**This section is the company's own statement, not the auditor's.** A
real SOC 2 report's Management's Assertion is written and signed by the
audited organization's management, asserting that the system description
is accurate and that controls were suitably designed (Type I) and
operated effectively (Type II) over the review period — the auditor then
independently tests that assertion, and the CPA firm's own opinion is a
separate, later section this pack never generates.

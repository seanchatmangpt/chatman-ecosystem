# RFC v26.9.25 — Semantic Procedural Graph and Anti-Reinvention Admission

**Status:** CANDIDATE  
**Owner:** chatman-ecosystem

## Decision

The ecosystem adopts two coupled laws.

### Epistemic Conway Corollary

Systems tend to reflect the topology of prior art reachable by their builders. A missing knowledge edge can therefore appear in software as an apparently novel abstraction.

### Anti-Reinvention Law

A new abstraction may be admitted as novel only after qualified prior art has been searched and shown insufficient for the required semantics.

```text
UnknownToBuilder != Novel
Unfamiliar != Unsupported
Candidate != Truth != Authority != DO != Standing
```

Formally:

```text
NOVEL_GAP(C) => ExistingQualifiedPriorArt !|= RequiredSemantics(C)
```

The proof obligation is operationalized by a durable prior-art search record. Missing research is not evidence of novelty.

## Semantic Procedural Graph

SPG is the ecosystem's interchange boundary for procedure identity, not a replacement for specialized formalisms.

```text
                    Semantic Procedural Graph
                              |
          +---------+---------+---------+---------+
          |         |         |         |         |
         HDDL      FOND      TLA+     OCEL 2.0   SA2A
          |         |         |         |         |
          +---------+---------+---------+---------+
                              |
                             BRCE
                              |
                              DO
                              |
                            Receipt
```

An SPG contains:

- stable semantic node identities;
- typed edges;
- guards and pre/postconditions;
- evidence requirements;
- authority requirements;
- consequence classes;
- failure modes and compensations;
- falsifiers;
- projection bindings;
- provenance.

SPG does not grant authority. It may describe a consequential edge, but execution remains BRCE-only.

## Prior-art routing

The default search order is:

```text
retrieve -> reuse -> compose -> extend -> invent
```

The initial public/formalism routing catalogue includes RDF/OWL/SHACL, PROV-O, P-Plan, PDDL, HDDL/HTN, FOND, TLA+, OCEL 2.0, process mining, SAT/SMT/CP, Datalog/Prolog, Lean 4, and OR.

The model may propose a routing candidate from latent knowledge. The authoritative source is still the retrieved standard/formalism and its qualified local binding.

## State

Graphs remain explicitly typed:

```text
CANDIDATE
ADMITTED
REFUSED(type)
```

The first court is repository-local and establishes structure only. It does not establish production execution or external standing.

## Graph evolution

Architectural evolution is represented as a semantic graph rewrite:

```text
G_(n+1) = G_n (+) DeltaG
```

Supported semantic diff classes include:

- ADD_NODE / REMOVE_NODE
- ADD_EDGE / REMOVE_EDGE
- CHANGE_GUARD
- CHANGE_AUTHORITY
- CHANGE_EVIDENCE
- CHANGE_CONSEQUENCE
- ADD_INVARIANT

Runtime execution and graph evolution remain separated:

```text
SELECT(G_n) != CONSTRUCT(DeltaG) != ADMIT(G_n (+) DeltaG) != DO
```

## Falsifier

This RFC is falsified in its current form if a required procedural property affects observable lawful execution and cannot be represented in SPG or explicitly bounded as unsupported.

The Anti-Reinvention Law is falsified if a construct receives NOVEL_GAP standing while an already-qualified prior-art candidate satisfies all required semantics under the same boundary and conditions.

## Initial executable court

```bash
python3 scripts/verify_spg_prior_art.py
python3 -m unittest tests.test_spg_prior_art -v
```

The court validates:

1. the prior-art routing catalogue;
2. the example SA2A -> BRCE procedure graph;
3. typed authority/evidence/receipt requirements for consequential edges;
4. projection identities for HDDL, TLA+, OCEL 2.0, SA2A and BRCE;
5. novelty claims cannot bypass prior-art search;
6. semantic diff reports behaviorally relevant changes.

Success establishes repository-local structural admission only.

# RFC-0005: v26.9.25 Autonomic Closure Amendment

**Status:** FINAL_SPEC — additive amendment to RFC-0004
**Release:** v26.9.25 (amendment text); term U binds from the next calver
**Role:** normative definition of autonomic closure (term U) and its gates
**Authority:** NONE
**Consequence:** documentation / admission contract only
**Implementation standing:** OPEN, evaluated by the chatman-ecosystem autonomic crown
**Supersedes:** none
**Amends:** [RFC-0004](0004-v26.9.25-self-closing-release.md) (additively; RFC-0004 text is unchanged)

Normative language: MUST, MUST NOT, SHALL, SHALL NOT, SHOULD, MAY have their usual RFC meanings.
Unqualified section references (for example "§39") refer to RFC-0004.

---

# 1. Abstract

RFC-0004 defines a release that closes semantically: intent, decomposition, formal reasoning,
manufacture, authority, verification, receipts, replay and standing form one system. It does not
require that the system runs that loop without a human operating it. This amendment adds the
missing term.

The operator formulas, verbatim:

```text
RELEASE = C∧A∧R∧X∧F∧M∧U
U = SelfStart∧SelfObserve∧SelfAdmit∧SelfDecompose∧SelfConstruct∧SelfActuate∧SelfVerify∧SelfRepair∧SelfReplay∧SelfContinue∧NoHiddenHuman∧NoRepeatedLLM
```

C, A, R, X, F and M are the six terms of the RFC-0004 release theorem (§3). U is autonomic
closure: every recurring edge of the release path is started, observed, admitted, decomposed,
constructed, actuated, verified, repaired, replayed and continued by admitted machinery, with no
hidden human operation and no repeated general-purpose LLM reconstruction.

This RFC defines U, the standings it produces, the edge graph it is measured on, eighteen gates
(U-01..U-18), the recoverability of each §39 failure class, falsifiers, the premise-set rule,
the internal-requirement law, the known trust gaps, the operator-only actions, non-goals and
acceptance.

---

# 2. Relation to RFC-0004

1. RFC-0004 is not modified. Its text, section numbering and v26.9.25 theorem remain as merged.
2. The v26.9.25 release theorem stays six terms (C∧A∧R∧X∧F∧M). v26.9.25 SHALL NOT be evaluated
   against U, and no v26.9.25 receipt SHALL be reinterpreted as evidence of U.
3. U applies from the next calver onward. A release on or after the next calver is RELEASED only
   if C∧A∧R∧X∧F∧M∧U holds on its exact crown subject.
4. Terminal does not imply autonomic (Terminal ⇏ Autonomic). A subject whose required rows are
   all terminal under RFC-0004 (§38, §48) MAY still be NOT_AUTONOMIC. Terminality is an execution
   property; autonomy is a property of who and what operates the edges that produced it.
5. Where this RFC and RFC-0004 both speak, RFC-0004 governs v26.9.25 and this RFC governs U.
   Nothing here relaxes an RFC-0004 requirement.

# 3. Term U

U is the conjunction of twelve predicates evaluated over the edge graph of §6 for one crown
subject (exact SHA).

| Conjunct | Holds when |
|---|---|
| SelfStart | every recurring cycle is started by a machine trigger (schedule, ref event, dependency event), never by a person running a command |
| SelfObserve | every observation the cycle consumes is gathered by admitted machinery from durable sources |
| SelfAdmit | every admission decision is computed by a gate that can and does refuse |
| SelfDecompose | objectives are decomposed into work orders by admitted machinery (Berthier, sJira), not restated by hand |
| SelfConstruct | candidate artifacts are manufactured by admitted generators or constructors |
| SelfActuate | every DO runs through BRCE under an admitted lease, with a receipt |
| SelfVerify | the verification ladder runs on the exact subject without human selection of checks |
| SelfRepair | recoverable failures (§8) are repaired and re-verified by machinery |
| SelfReplay | every receipt can be replayed from durable state alone |
| SelfContinue | independent work continues when one edge fails unrecoverably, and the next cycle is scheduled by the loop itself |
| NoHiddenHuman | no human operational dependency exists on any edge (§5) |
| NoRepeatedLLM | no general-purpose LLM call sits on a formalized recurring path |

U holds only when all twelve hold. A conjunct with no evidence is UNKNOWN, and UNKNOWN is not
admitted.

# 4. Orthogonal Standings

A crown evaluation produces three independent standings.

| Axis | Values | Question answered |
|---|---|---|
| execution | ALIVE, PARTIAL_ALIVE, BLOCKED(type), UNSUPPORTED(gap), REFUSED(type), UNKNOWN | did the subject run and verify on its exact SHA |
| autonomy | AUTONOMIC, NOT_AUTONOMIC, UNKNOWN | did machinery operate every recurring edge (term U) |
| authority | AUTHORIZED, WAITING_EXTERNAL_AUTHORITY, REFUSED(AUTHORITY_FAILURE) | does an admitted grant exist for the consequential transition |

The axes are orthogonal: none is computed from another, and a report SHALL state all three.

One implication binds them: AUTONOMIC ⇒ ALIVE. A loop that is not observed to execute on its
exact subject cannot be shown to operate itself.

Legal combinations:

| execution | autonomy | authority | Legal | Meaning |
|---|---|---|---|---|
| ALIVE | AUTONOMIC | AUTHORIZED | yes | full closure; the release may proceed |
| ALIVE | AUTONOMIC | WAITING_EXTERNAL_AUTHORITY | yes | loop is autonomic; a human authority gate is pending (§5) |
| ALIVE | NOT_AUTONOMIC | AUTHORIZED | yes | works, but some edge is operated by a human or repeated LLM |
| ALIVE | NOT_AUTONOMIC | WAITING_EXTERNAL_AUTHORITY | yes | expected standing of the first post-v26.9.25 evaluation |
| ALIVE | UNKNOWN | any | yes | autonomy not yet measured |
| PARTIAL_ALIVE, BLOCKED, UNSUPPORTED, REFUSED, UNKNOWN | NOT_AUTONOMIC or UNKNOWN | any | yes | execution incomplete |
| PARTIAL_ALIVE, BLOCKED, UNSUPPORTED, REFUSED, UNKNOWN | AUTONOMIC | any | no | violates AUTONOMIC ⇒ ALIVE |
| any | any | REFUSED(AUTHORITY_FAILURE) with a DO receipt | no | actuation without authority (§17 of RFC-0004) |

An evaluator that emits an illegal combination SHALL itself be REFUSED(VERIFICATION_FAILURE).

# 5. HumanAuthorityGate and HumanOperationalDependency

HumanAuthorityGate ≠ HumanOperationalDependency.

A **HumanAuthorityGate** is an admitted point where a person grants or withholds authority for a
consequential transition: approving a protected environment, granting a lease, publishing. It is
declared in advance, recorded on the edge (`authority_gate`), and its outcome is receipted. A
HumanAuthorityGate does not break U. While pending, it yields authority standing
WAITING_EXTERNAL_AUTHORITY.

A **HumanOperationalDependency** is any point where the loop only proceeds because a person
performs operational work: running a command, restating an objective, supplying evidence by hand,
choosing which check to run, retrying a job, copying a digest. It breaks NoHiddenHuman, and U does
not hold while one exists on a recurring edge.

Classification rule: an edge whose human involvement is not declared as an `authority_gate`, or
whose human act produces data rather than a grant, is a HumanOperationalDependency.

# 6. Edge Graph Schema

Autonomy is measured on `edges.json`: one object per edge of the recurring release path.

Stage order (each edge names exactly one stage):

```text
start → observe → admit → decompose → construct → actuate → verify → repair → replay → continue
```

Schema:

```json
{
  "schema": "edges.v1",
  "crown_subject": "<40-hex sha>",
  "edges": [
    {
      "id": "<stable edge id>",
      "stage": "start|observe|admit|decompose|construct|actuate|verify|repair|replay|continue",
      "from": "<node id>",
      "to": "<node id>",
      "owner_kind": "machine|human|llm",
      "authority_gate": null,
      "recurring": true,
      "evidence": {
        "kind": "<receipt|run|log|workflow|policy>",
        "locator": "<durable locator>",
        "sha256": "<64-hex digest of the located bytes>"
      }
    }
  ]
}
```

Field rules:

1. `owner_kind` records who operates the edge today, not who should.
2. `authority_gate` is `null` or an object `{ "grantor": "<role>", "grant": "<what is granted>" }`.
   Only an edge with a non-null `authority_gate` may have a human in the loop without breaking
   NoHiddenHuman, and only for the grant itself.
3. `recurring` is true when the edge runs on every cycle. Gates U-01 to U-03 range over recurring
   edges.
4. `evidence.locator` SHALL use the durable locator grammar:
   `git:<owner/repo>@<40hex>:<path>`, `git-notes:refs/notes/<ref>@<40hex>`, or `https://...`.
   Absolute, scratch, temporary and home-relative paths are never evidence locators.
5. `evidence.sha256` SHALL be recomputed from the located bytes by the evaluator; a stored digest
   that is not recomputed is not evidence.

The inventory SHALL be honest: an edge operated by a person today is recorded with
`owner_kind: "human"` even when it is planned for automation.

# 7. Autonomy Gates

U holds on a crown subject only when every gate below meets its threshold on that subject.

| id | name | metric | threshold | evidence kind |
|---|---|---|---|---|
| U-01 | machine-owned edges | recurring edges with `owner_kind: machine` ÷ recurring edges | 100% | edges.json |
| U-02 | human operations | recurring edges with a HumanOperationalDependency | 0 | edges.json |
| U-03 | general LLM calls | general LLM calls on a formalized recurring path | 0 | edges.json, run logs |
| U-04 | exact evidence | edges whose evidence has a durable locator and recomputed sha256 | 100% | edges.json, recomputed digests |
| U-05 | recoverable repair | injected recoverable failures repaired and re-verified | 100% | fault-injection receipts |
| U-06 | unrecoverable containment | unrecoverable failures typed while independent work continues | 100% | fault-injection receipts |
| U-07 | semantic mutants | semantic mutants of the crown and gates killed | 100% | mutation receipts |
| U-08 | authority amplification | authority-amplification attempts accepted | 0 | refusal receipts |
| U-09 | unreceipted DO | unreceipted or duplicate DO | 0 | BRCE receipts, reconciliation log |
| U-10 | kill between DO and receipt | kills between DO and receipt that reconcile exactly once | 100% | reconciliation receipts |
| U-11 | cold reconstruction | reconstruction from durable state after deleting runner, workspace and artifacts | 100% | replay receipts |
| U-12 | objective mutation | admitted objective mutations that close affected repos without manual restatement | 100% | premise-set receipts |
| U-13 | pinned toolchain | unpinned actions or toolchains on the path | 0 | workflow scan |
| U-14 | hidden local state | hidden local state the path depends on | 0 | durability scan |
| U-15 | unchanged retry | retries with unchanged input and unchanged hypothesis | 0 | run history |
| U-16 | internal blockers | internal blockers at an AUTONOMIC crown | 0 | crown receipt |
| U-17 | scheduler independence | removing the primary scheduler stops the controller | false | scheduler-removal receipt |
| U-18 | clean cycles | independent clean cycles | 3/3 | cycle receipts |

Gate notes:

1. U-05 and U-06 use the recoverability fixed in §8; an evaluator SHALL NOT reclassify a class.
2. U-10 counts kills injected after actuation and before the receipt is durable. Exactly once
   means one receipt and zero duplicate effects after reconciliation.
3. U-15 follows §40: a retry is admitted only with a new hypothesis or changed input.
4. U-17 is false when a secondary trigger (for example a ref event or a dependency event) resumes
   the controller within one cycle after the primary schedule is removed.
5. U-18 cycles are independent when they run on distinct subjects with no shared runner state.

A gate with no measurement is BLOCKED with a typed class and a `broken_term`; it is never PASS.

# 8. Crown Self-Attack Recoverability

The autonomic crown SHALL attack itself with one injected fault per §39 class. Recoverability is
fixed by this table; U-05 counts R rows, U-06 counts U rows.

| §39 class | Variant | Recoverability | Required response |
|---|---|---|---|
| TRANSPORT_FAILURE | any | R | re-observe through the same or an alternate transport |
| BUILD_FAILURE | any | R | regenerate from the canonical source, then rebuild |
| VERIFICATION_FAILURE | transient | R | re-verify once with a recorded new hypothesis |
| VERIFICATION_FAILURE | deterministic | U | type the failure; continue independent work |
| AUTHORITY_FAILURE | any | U | refuse; no amplification; wait for a HumanAuthorityGate |
| EVIDENCE_FAILURE | stale | R | re-observe and recompute the digest |
| EVIDENCE_FAILURE | forged chain | U | refuse the chain; quarantine the evidence |
| DEPENDENCY_FAILURE | local NEW_HEAD | R | re-evaluate against the new head |
| DEPENDENCY_FAILURE | remote producer | U | type as WAITING_PRODUCER; continue independent work |
| CAPABILITY_GAP | any | U | type as UNSUPPORTED(gap); continue independent work |
| MODEL_COUNTEREXAMPLE | any | U | preserve the counterexample; refuse the subject |
| SUBJECT_FAILURE | crown-sha split | R | re-bind to the current crown subject and re-evaluate |

R means recoverable: the crown SHALL repair and re-verify without a human. U means unrecoverable:
the crown SHALL type the failure, preserve its evidence, and continue every independent edge.
Transport failure SHALL NOT be rewritten as subject failure (§39).

# 9. Falsifiers

F_U, the falsifier of the operator's intent: U is false on a crown subject if any recurring edge
of its release path proceeds only because a person operated it or a general-purpose LLM
reconstructed it, whether or not that fact appears in any receipt.

Per-gate falsifiers (each is an observation that makes the gate fail):

| Gate | Falsifier |
|---|---|
| U-01 | a recurring edge with `owner_kind` human or llm on an AUTONOMIC subject |
| U-02 | a recurring edge whose human act supplies data rather than a declared grant |
| U-03 | a general LLM call found in the logs of a formalized recurring path |
| U-04 | an evidence locator outside the durable grammar, or a digest that does not recompute |
| U-05 | an injected R-class fault that ends without a repair receipt and a re-verification |
| U-06 | an injected U-class fault that halts an independent edge, or ends untyped |
| U-07 | a semantic mutant of the crown or a gate that survives |
| U-08 | a request exceeding its lease that is accepted |
| U-09 | a DO with no receipt, or two effects for one intent |
| U-10 | a kill between DO and receipt that reconciles zero or two times |
| U-11 | a receipt that cannot be replayed after the runner, workspace and artifacts are deleted |
| U-12 | an admitted objective mutation that closes only after a person restates it |
| U-13 | an action referenced by tag or branch, or a floating runner or toolchain label |
| U-14 | a path that fails when an undeclared local file, cache or environment variable is removed |
| U-15 | two runs with identical input and identical hypothesis after a failure |
| U-16 | an AUTONOMIC crown receipt listing an internal BLOCKED subject |
| U-17 | a controller that stays stopped after the primary scheduler is removed |
| U-18 | fewer than three independent clean cycles, or cycles sharing runner state |

# 10. Premise-Set Rule

A release premise is a set of RFCs, not a single document.

1. Premise keys have the form `premise:<RFC>#§n`, for example `premise:RFC-0005#§7`.
2. An unqualified reference (`§n` with no RFC) binds RFC-0004.
3. The premise digest is computed over the mapping from RFC identifier to source digest. A
   single-premise evaluation SHALL produce output byte-identical to the evaluation that preceded
   this rule.
4. The first U-12 test is the Berthier recompile for the premise set {RFC-0004, RFC-0005}: the
   strategic compiler recompiles the objective graph from both documents and closes the affected
   repositories with ManualRestatementCount = 0. Any count above zero fails U-12.

# 11. Internal-Requirement Law

AUTONOMIC(crown) requires AUTONOMIC(s) for every required internal subject s.

A required internal subject is any subject the crown's closure set requires and whose repository
is inside the release's authority boundary. External producers are excluded; they are typed
WAITING_PRODUCER under §8 and do not block U, but they cannot be claimed as autonomic either.

A crown SHALL NOT be AUTONOMIC while any required internal subject is NOT_AUTONOMIC or UNKNOWN.
This is what U-16 measures.

# 12. Trust Gaps

Known gaps between the v26.9.25 implementation and U, with typed dispositions. Each gap blocks the
gate named; none is waived.

| Gap | Blocks | Disposition |
|---|---|---|
| crown chain receipts stored only as Actions artifacts with 90-day retention | U-04, U-11 | BLOCKED(EVIDENCE_FAILURE), broken_term R_missing_replay; move receipts out of subject to a durable locator |
| actions referenced by mutable tags and runner `ubuntu-latest` | U-13 | BLOCKED(DEPENDENCY_FAILURE), broken_term R_missing_identity; pin actions by commit and runner by image digest |
| default branch `main` unprotected | U-08 | BLOCKED(AUTHORITY_CONFIGURATION), broken_term R_missing_authority; operator-only (§13) |
| `release-crown` environment with no required reviewer | U-08 | BLOCKED(AUTHORITY_CONFIGURATION), broken_term R_missing_authority; operator-only (§13) |
| a BLOCKED crown only warns instead of failing the run | U-16 | BLOCKED(VERIFICATION_FAILURE), broken_term admission_vacuous; make the autonomic job fail on a refusal |
| `test_loop` re-evidence supplied by hand | U-02, U-14 | BLOCKED(EVIDENCE_FAILURE), broken_term mu_on_O; derive re-evidence from durable observation |

# 13. Operator-Only Actions

The following actions require authority no machine edge holds. Until performed, each is
BLOCKED(AUTHORITY_CONFIGURATION) with broken_term R_missing_authority, and the authority
standing is WAITING_EXTERNAL_AUTHORITY.

1. Enable branch protection on `main` of each repository in the closure set.
2. Add required reviewers to the `release-crown` environment.
3. Grant any lease that lets a crown write, tag, publish or deploy.

These are HumanAuthorityGates (§5). Performing them does not break U; leaving them undone does
not make a loop NOT_AUTONOMIC, but it keeps authority standing at WAITING_EXTERNAL_AUTHORITY.

# 14. Non-Goals

1. No retroactive claim: v26.9.25 is not declared AUTONOMIC, and no v26.9.25 receipt is
   reinterpreted under U.
2. No write authority: this amendment grants no crown, controller or agent any authority to
   write, tag, publish or deploy.
3. No SelfConstruct or SelfActuate implementation: this amendment defines those conjuncts and
   their gates; it does not implement them.
4. No dependency on SPG: nothing here depends on the SPG work (including SPG PR #275), which is not
   in the v26.9.25 tag and remains a next-calver input.

# 15. Acceptance

This amendment is accepted when all of the following hold on the merge commit of the repository
that carries it:

1. RFC-0004 is byte-identical to its pre-amendment content.
2. This document contains the operator formulas of §1 verbatim and sections 1 through 15.
3. The documentation checks and the semantic root qualification pass on the exact head.
4. The engineering documentation index lists this RFC after RFC-0004.

Implementation acceptance is separate: the first autonomic crown evaluation on or after the next
calver SHALL emit all three standings of §4, a gate result for each of U-01..U-18 with evidence
or a typed BLOCKED, and the §8 self-attack results. The expected first standing is execution
ALIVE, autonomy NOT_AUTONOMIC, authority WAITING_EXTERNAL_AUTHORITY; an evaluator that reports
AUTONOMIC while any §12 gap is open is falsified.

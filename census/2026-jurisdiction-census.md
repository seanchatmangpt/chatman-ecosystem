## Summary: observed jurisdiction violations (INFERRED, not yet mechanically enforced)

1. **beam4pm**: process-mining/planning repo also owns first-party actuation code + its own receipt chain.
2. **ash_a2a**: dispatch/projection layer also owns `planning.ex` and `execute_command.ex` directly.
3. **autofde-lab**: explicitly disclaims actuation in its own doctrine, yet contains `openclaw_runtime.py` and a duplicated `gymact/` ontology namespace — the repo's own rules docs already name this as a live tension.
4. **mfw**: two differently-scoped `runtime/` directories — naming/consolidation smell, not confirmed as a semantic violation.
5. **gymact**: authority/receipt/runtime logic duplicated across Rust (`rust/crown`) and Python (`src/gymact/*_runtime.py`) — internal, not cross-repo, duplication.

**bcinr** bundling planner+actuator+auditor is explicitly ADMITTED as by-design umbrella scope, not classified as a violation.
